# API assets (PDF letterhead)

Place **`brand2school.png`** here (recommended: 520×200px or similar, transparent background).

PDFKit embeds PNG in ESG reports (`esgPdf.ts`). SVG from the web app is not used for PDF output.

Also accepted: `brand2school.png` at the monorepo root or `apps/web/public/brand2school.png`.
